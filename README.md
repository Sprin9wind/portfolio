# 이정훈 게임 기획 포트폴리오

- 공개 사이트: https://sprin9wind.github.io/portfolio/
- 본문 편집기: https://sprin9wind.github.io/portfolio/admin.html
- 저장소: https://github.com/Sprin9wind/portfolio

이 저장소는 공개 저장소입니다. `main` 브랜치의 루트 폴더를 GitHub Pages로 배포합니다. 로컬 미리보기와 달리 공개 사이트는 작업 PC가 꺼져 있어도 접속할 수 있습니다.

## 다른 기기에서 관리하기

### 브라우저에서 본문 수정

1. 사이트에서 `편집`을 누르면 보고 있던 프로젝트의 문서가 열립니다. 왼쪽 목록에서 다른 문서를 고를 수 있습니다.
2. 글은 직접 입력합니다. 이미지는 클릭한 뒤 배치 도구에서 너비, 정렬, 교체, 설명, 순서를 바꿉니다. 기획서 묶음은 한 줄 또는 두 칸으로 바꾸고, `+ 글과 이미지 두 칸`으로 새 배치를 추가할 수 있습니다.
3. `편집본 미리보기`에서 아직 공개하지 않은 변경을 확인합니다.
4. 처음 사용하는 브라우저에서는 `관리 및 도움말 → GitHub 연결`을 설정합니다. 저장소 `Sprin9wind/portfolio`, 브랜치 `main`은 기본 입력되어 있고 폴더 경로는 비워 둡니다. 본인 토큰을 입력하고 연결을 저장합니다.
5. `사이트에 반영`을 누릅니다. GitHub 저장 후 공개 사이트 배포까지 잠시 시간이 걸릴 수 있습니다.

편집기의 임시 작업본과 GitHub 연결 정보는 해당 브라우저에 저장됩니다. 다른 PC나 모바일로 옮기기 전에는 GitHub 저장까지 완료하세요. 다른 기기의 작업본이 오래되었다면 최신 원본을 불러온 뒤 수정하세요. 동시에 두 기기에서 같은 내용을 수정하면 충돌할 수 있습니다.

`관리 및 도움말 → 최신 내용 불러오기`는 현재 작업본을 버전 기록에 보관한 뒤 최신 내용으로 교체합니다. 저장 충돌이 나면 양쪽 내용을 보관하고 내 작업본을 선택할 수도 있습니다. 그 상태에서 다시 `사이트에 반영`하면 다른 기기의 본문 수정을 내 작업본으로 교체합니다.

PNG 기획서 안의 글자는 직접 입력해서 고칠 수 없습니다. 주변 설명과 이미지 배치를 수정하거나 새 이미지로 교체하세요. 기획서 HTML, Markdown 원고는 별도 파일이므로 본문 편집과 자동으로 동기화되지 않습니다. Ctrl+Z는 현재 문서 본문에 적용되며, 제목, 프로필과 문서 변경 전 내용은 `관리 및 도움말 → 버전`에서 복원합니다.

GitHub 접근 토큰은 편집기의 연결 설정에서만 입력합니다. 소스 파일, 기획 문서, 커밋에 넣지 않습니다. 공용 기기에서는 연결 정보를 저장하지 마세요.

### 사이트 구조와 기획서 수정

GitHub 웹에서 파일을 편집하거나 GitHub Desktop으로 이 저장소를 복제할 수 있습니다. 작업을 시작할 때 최신 변경을 가져오고, 작업을 마치면 커밋과 Push까지 완료하세요. 상세한 화면 수정과 여러 이미지 작업에는 PC가 편리합니다.

편집기에서 생성하는 `data.js`는 본문 데이터입니다. 사이트 구조, 기획서 HTML/Markdown, 폰트, 동영상 파일의 변경은 해당 파일도 함께 커밋해야 합니다. 편집기 GitHub 저장만으로 기존 로컬 폴더의 새 파일이 모두 업로드되지는 않습니다.

Git은 커밋한 프로젝트 파일을 공유합니다. AI 도구의 로그인, 대화 세션, 브라우저 임시 작업본, 실행 중인 로컬 서버는 기기 간에 자동으로 옮겨지지 않습니다.

## 파일 구성

| 경로 | 용도 |
| --- | --- |
| `index.html` | 포트폴리오 화면과 스타일 |
| `admin.html` | 본문 편집기 |
| `data.js` | 소개, 프로젝트, 모의면접 내용 |
| `docs/` | 기획서 Markdown과 읽기용 HTML |
| `images/` | 문서 이미지, 도식, 도구 아이콘 |
| `media/` | 모션 영상과 GIF |
| `fonts/` | 로컬 웹폰트와 출처 |
| `sim/` | 전투 시뮬레이터와 데이터 |
| `CLAUDE.md` | 작업 기준과 이어서 작업할 때의 주의사항 |
| `HISTORY.md` | 주요 수정 기록 |

기획서를 수정하면 Markdown, HTML, 문서 PNG와 본문 설명을 함께 맞춥니다. 제목과 소제목은 NanumSquareNeo ExtraBold, 본문은 Pretendard입니다. 사이트는 기존 배너와 배치를 유지하며 파란 키컬러를 사용합니다.

## 로컬 미리보기 (선택)

Python이 설치되어 있다면 저장소 폴더에서 실행합니다.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/`를 엽니다. 이 주소는 서버를 실행한 PC에서만 사용할 수 있습니다. 다른 기기에는 위 공개 사이트 주소를 공유하세요.

`.work/`는 원문 추출물, 임시 검수 파일과 로컬 실행 로그를 보관하는 작업 폴더이며 Git에 올리지 않습니다.
