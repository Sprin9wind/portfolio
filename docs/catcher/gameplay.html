포수 사인과 이닝 진행

● 손동작을 배합 판단으로 연결

  • 플레이어는 포수 역할을 맡아 타자의 특성과 약점을 보고 구종과 투구 위치를 정한다.
  • 키보드의 이동 입력을 손동작으로 대체하는 데서 나아가, 사인을 내는 행동 자체가 포수의 역할이 되도록 한다.
  • 웹캠으로 입력한 사인에 따라 투수가 공을 던지고, 타격 결과와 아웃 카운트에 따라 게임을 진행한다.

구종과 위치를 나눠 입력받아 두 판단을 순서대로 진행한다. 손을 어디로 움직였는지만 읽는 방식이 아니라, 각 구종과 구역에 대응하는 제스처를 분류해 입력값으로 사용한다.

타자 약점과 투구 결과

● 타자별 특성이 사인 선택에 주는 의미

  • 타자마다 결과 확률과 약점 조건을 둔다. 플레이어는 표시된 특성을 보고 구종이나 코스를 선택한다.
  • 약점은 구종 조건 또는 위치 조건으로 구분한다. 예를 들어 빠른 공에 약한 타자는 패스트볼이나 투심 패스트볼을, 몸쪽 공에 약한 타자는 몸쪽 코스를 조건으로 사용한다.
  • 약점에 맞춘 사인은 유리한 결과의 확률을 높인다. 특정 사인을 냈다고 결과가 항상 같아지는 구조는 아니다.

● 약점 조건에 따른 확률 보정

조건을 만족하면
안타 확률 −5%p / 홈런 확률 −5%p / 스트라이크 확률 +10%p
  • 소수로 표현한 확률에서 0.05를 빼거나 0.1을 더한다. 기존 확률의 5%를 곱해 줄이는 방식이 아니다.
  • 플라이아웃 확률은 이 보정에서 바꾸지 않는다.
결과 항목 기본 확률 예시 약점 조건 충족 후
스트라이크 30.0% 40.0%
플라이아웃 38.8% 38.8%
안타 21.2% 16.2%
홈런 10.0% 5.0%
합계 100.0% 100.0%

기본 데이터에서 안타 확률과 홈런 확률의 합은 타율에 해당한다. 위 예시에서는 21.2% + 10.0% = 31.2%다. 약점 보정을 적용하면 이 합이 21.2%로 줄어든다.

● 타자 데이터의 구성

항목 역할
이름, 타율 타자 정보를 표시한다. 타율은 기본 안타 확률과 홈런 확률의 합이다.
Strike / Flyout / Hit / HomeRun 결과별 확률을 정의한다. 표시용 타율과 안타 결과 확률을 구분한다.
특성 설명 플레이어가 구종과 코스를 선택할 단서를 제공한다.
조건 입력 구종 또는 위치가 약점에 해당하는지 판단한다.

● 구현 결과와 보완점

  • 약점 보정은 위 확률표의 스트라이크, 플라이아웃, 안타, 홈런 항목을 기준으로 설명한다.
  • 번트와 파울, 투수도 함께 변화하는 구성은 당시 구현 결과에 포함하지 않는다. 이후 게임의 선택과 변수를 확장할 수 있는 보완 방향이다.
