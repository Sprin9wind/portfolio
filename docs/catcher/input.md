# 제스처 입력과 게임의 연결

## ● 초기 이동 조작에서 포수 사인으로

| 단계 | 손동작이 입력하는 정보 | 확인한 구현 범위 |
| --- | --- | --- |
| 초기 프로토타입 | 앞, 뒤, 좌, 우, 점프, 정지 | 인식한 제스처를 텍스트로 전송하고 Unity의 이동 입력에 연결 |
| 포수 시뮬레이터 | 구종 6종과 위치 9개 | 각 제스처의 각도 데이터를 수집하고 분류 결과를 전송 |
| 영상 전송 추가 | 인식 결과와 웹캠 화면 | 텍스트와 인코딩한 영상을 함께 보내 게임 내 카메라 UI에 표시할 수 있도록 구성 |

교수님의 피드백을 바탕으로 이동 키를 대체하던 주제를 포수의 사인 전달로 전환했다. 입력 장치의 차이를 보여주는 데서, 손동작이 게임 속 역할과 직접 연결되도록 방향을 바꾼 것이다.

## ● 손동작을 구분하는 과정

<div class="flow"><div>웹캠 영상</div><b>→</b><div>손의 특징점<br><small>MediaPipe</small></div><b>→</b><div>관절 각도<br><small>벡터 정규화와 내적</small></div><b>→</b><div>제스처 분류<br><small>OpenCV KNN</small></div></div>

- MediaPipe로 손의 특징점 좌표를 얻고, 관절 사이 벡터로 각도를 계산한다.
- 제스처마다 각도 데이터와 분류 이름을 짝지어 CSV 데이터셋으로 저장한다.
- KNN은 입력 각도와 학습 데이터의 가까운 표본을 비교해 제스처를 분류한다. 손동작의 의미는 구종과 위치에 맞춘 라벨로 정한다.

## ● Unity에 전달하는 정보

| 전달 항목 | Python에서 처리 | Unity에서 사용할 내용 |
| --- | --- | --- |
| 인식 결과 | 구종 또는 위치 이름을 텍스트로 변환 | 게임 입력값 |
| 웹캠 화면 | 프레임을 이미지로 인코딩 | 카메라 UI에 표시할 영상 |

<div class="flow"><div>Python<br><small>인식 결과 + 영상 인코딩</small></div><b>→</b><div>UDP 전송</div><b>→</b><div>Unity<br><small>게임 입력과 카메라 UI</small></div></div>

## ● 담당 범위

주제와 모델 선정, 제스처 데이터 수집과 인식 프로그램, Unity로 보내는 전송부를 구현했다. 게임 진행 흐름, 타자 정보, 구종별 궤적과 화면 UI의 기초 기획안을 작성하고 야구장과 선수 에셋을 함께 전달했다. 게임을 구성하는 Unity 개발은 팀원이 담당했다.
