5.1 작업 관리와 회고

● 회의록과 발표 피드백 정리

프로젝트 매니징을 맡아 Confluence 회의록의 질문, 답변과 메모를 구조화하고
발표 자료와 피드백을 함께 정리했습니다.

실제 정리한 문서 구성한 내용
2026/09/30 회의록 담당과 질문자, 질문/답변 표, 작성자 메모
1차 프로토 발표회 다른 조 자료 조별 섹션, 게임 개요, 발표 순서에 따른 슬라이드와 캡션
1차 프로토 우리 조 피드백 발표 슬라이드 13장과 피드백을 한 문서에서 확인하도록 구성

● 구현과 통합의 담당 구분

개인 브랜치 작업 → 구현 검증 → Unity 패키지 내보내기 → 적용 문서 작성 → 통합 담당자 반영의 흐름을 정리했습니다.
적용 문서에는 필요한 컴포넌트, 연결 조건, 확인 결과와 남은 항목을 기록했습니다.

● 회고와 반영

발견한 문제 이후 작업에 반영한 기준
모션 후보가 많아도 비교 조건이 다르면 선택하기 어려움 속도, 하체처럼 유지할 조건과 팔 궤적처럼 바꿀 부위를 나눠 요청
Blender에서 선택한 자세가 Unity에서 달라짐 제작 완료와 적용 완료를 구분하고 표본 자세 대조와 상태 전환 확인을 인계 내용에 포함
