5.1 제작, 검증, 인계 기준

● 작업 단위

기획 조건과 완료 기준을 먼저 정한 뒤, 구현, 검증, 통합의 담당 범위를 구분한다.

단계 필요한 입력 산출물, 확인 사항
기획 목적, 적용 대상, 플레이 규칙 요구사항과 제외 범위
구현 요청 담당 파일, 원본, 레퍼런스, 고정 조건 후보 또는 구현 결과
검토 동일 조건의 비교 자료 채택안, 수정할 부위, 재작업 사유
통합 확정된 결과와 적용 방법 연결 상태, 참조 관계 확인
검증 재현 조건과 예상 동작 실행 결과, 실패 항목, 미확인 항목
인계 적용 파일과 검증 기록 다음 담당자가 수행할 작업

● 협업 규칙

  • 에이전트별 수정 파일을 나누고 공통 파일의 통합 담당을 지정.
  • Unity 씬을 동시에 수정하지 않도록 에디터 쓰기 담당을 일원화.
  • 원본 에셋과 작업본을 분리하고, 채택한 버전을 명시.
  • 검사 통과와 실제 플레이 확인을 구분하여 기록.

● 인계 문서의 필수 항목

항목 예시
적용 대상 캐릭터, 꼬리, 전화부스 등 연결할 오브젝트
연결 조건 필요한 컴포넌트, 참조 대상, 호출 시점
재현 방법 대결 진입, 문 개폐, 리스폰 등 확인 절차
검증 결과 실제 실행한 검사와 확인한 동작
남은 작업 배포 빌드, 다중 접속 등 별도로 확인할 항목

● 완료 판정

파일 전달만으로 완료 처리하지 않는다. 적용 방법과 검증 기록을 함께 남기고, 미확인 항목은 다음 작업으로 넘긴다.
