# 꼬리 잡기_저항 미니게임

## ● 저항 미니게임 개요

꼬리를 잡았다고 바로 승부가 끝나지는 않는다.<br>**잡은 플레이어와 잡힌 플레이어가 C와 V를 번갈아 눌러, 최대 5초 동안 대결한다.**

| 구분 | 내용 |
| --- | --- |
| 참여자 | 공격자: 타깃의 꼬리를 잡은 플레이어<br>수비자: 꼬리를 잡힌 플레이어 |
| 목표 | 공격자는 꼬리를 빼앗아 타깃을 탈락시킨다.<br>수비자는 잡기를 뿌리쳐 살아남는다. |
| 조작 | 양쪽 모두 C부터 시작해 C → V → C 순서로 교대 입력한다.<br>다음에 눌러야 하는 키를 화면에서 강조한다. |
| 시간과 판정 | 최대 5초. 게이지가 한쪽 끝에 닿으면 즉시 종료한다.<br>시간이 끝나면 우세한 쪽이 이기며, 중앙이면 수비자가 탈출한다. |
| 시도와 배율 | 공격자별로 라운드 내 미니게임 진입 횟수를 센다. 공격 입력 배율은 최대 3단계다.<br>첫 진입 ×0.8 → 두 번째 ×1.0 → 세 번째부터 ×1.2. 이후에도 대결할 수 있다. |

## ● 설계 의도

- 꼬리를 잡힌 뒤에도 저항할 기회를 남겨, 수비자가 마지막 순간까지 생존을 위해 행동하도록 한다.
- 공격자의 첫 대결에서는 수비자가 뿌리치기 쉽도록 한다.<br>라운드 중 공격자가 대결을 거듭하면 입력당 게이지 이동량을 늘려, 반복된 추격이 포획으로 이어지도록 한다.
- 대결 중에는 수비자에게 공격자의 얼굴, 이름과 꼬리 색을 숨긴다.<br>탈출하면 별도 정체 공개 연출 없이 추격을 재개하고, 포획됐을 때 공격자를 공개한다.

# 꼬리 잡기_게이지 UI와 입력 안내

## ● C / V를 선택한 이유

- 오른손은 마우스에 둔 채, WASD로 이동하던 왼손을 가까운 C / V로 옮겨 교대 입력하도록 한다.
- 추격에서 저항 미니게임으로 전환할 때 손의 이동 부담을 줄이려는 의도다.

## ● 화면 배치

- 미니게임 패널은 **화면 하단 중앙**에 배치해 두 캐릭터가 보이는 중앙 영역을 가리지 않는다.
- 조작 키, 남은 시간, 대결의 우세를 한 패널에 모아 확인하도록 한다.

## ● 번호별 표시와 동작

| 번호 | 요소 | 표시와 변화 |
| --- | --- | --- |
| 1 | C / V 조작 키 | C부터 시작하며, 다음에 눌러야 하는 키를 강조한다.<br>유효 입력이 들어오면 반대 키로 강조를 옮기고, 눌린 상태도 표시한다. |
| 2 | 남은 시간 | 5.0초에서 시작해 남은 시간을 소수점 한 자리로 표시한다. |
| 3 | 시간 막대 | 처음에는 가득 차 있다.<br>남은 시간에 맞춰 오른쪽 끝점이 왼쪽으로 이동한다. |
| 4 | 우세 게이지 | 중앙에서 시작한다.<br>공격 입력은 경계점을 오른쪽으로, 수비 입력은 왼쪽으로 옮긴다. |

## ● 게이지와 종료 판정

| 경계점 위치 | 판정 |
| --- | --- |
| 대결 중 오른쪽 끝에 도달 | 공격자 승리. 즉시 포획한다. |
| 대결 중 왼쪽 끝에 도달 | 수비자 승리. 즉시 탈출한다. |
| 시간 종료 시 중앙보다 오른쪽 | 공격자 승리. 포획한다. |
| 시간 종료 시 중앙 또는 왼쪽 | 수비자 승리. 탈출한다. |

- **정보 구분:** 시간 막대는 남은 시간, 우세 게이지는 대결의 우세를 나타낸다.<br>두 정보를 위아래로 분리한다.
- **정체 숨김:** 수비자 화면에서는 공격자의 꼬리 색이 게이지에 드러나지 않게 한다.<br>패널에도 상대의 이름이나 얼굴을 표시하지 않는다.

# 꼬리 잡기_진입 조건과 상세 규칙

## ● 진입 조건

| 항목 | 처리 기준 |
| --- | --- |
| 대상과 접촉 | 지정된 타깃을 향한 잡기 모션 중, 손 판정 영역과 꼬리 판정 영역(콜라이더)이 접촉하면 시작한다.<br>두 캐릭터 사이를 가리는 물체가 없어야 한다. |
| 재시도 | 잡기를 시도하면 성공 여부와 관계없이 2초 동안 다시 시전할 수 없다. |
| 제외 상태 | 탈락, 대결 중, 넉백, 차량 탑승, 입력 잠금 상태에서는 시작하지 않는다. |

## ● 입력과 게이지 수치

| 항목 | 기준 |
| --- | --- |
| 유효 입력 | 양쪽 모두 C부터 시작해 번갈아 입력한다. 같은 키의 연속 입력은 반영하지 않는다. |
| 시간과 시작점 | 최대 5초, 전체 게이지의 중앙(50%)에서 시작한다. |
| 입력 이동량 | 전체 게이지를 100%로 본다. 수비는 입력 1회당 왼쪽으로 4%,<br>공격은 4%에 시도 배율을 적용한 만큼 오른쪽으로 이동시킨다. |
| 동시 입력 | 양쪽의 동시 입력을 함께 반영한 뒤 승패를 판단한다.<br>이동량이 같으면 서로 상쇄한다. |
| 종료 | 끝점에 닿으면 즉시 판정한다. 시간 종료 시 공격 우세면 포획, 중앙 또는 수비 우세면 탈출한다. |

## ● 시도 횟수에 따른 공격 배율

| 공격자의 진입 | 배율 | 1회 이동 비율 | 의도 |
| --- | --- | --- | --- |
| 첫 번째 | ×0.8 | 약 3% | 같은 속도로 입력하면 수비자가 우세하다. |
| 두 번째 | ×1.0 | 4% | 입력당 이동량이 같아 속도와 정확도로 겨룬다. |
| 세 번째부터 | ×1.2 | 약 5% | 같은 속도로 입력하면 공격자가 우세하다. |

- **표시 기준:** 이동 비율은 전체 게이지 대비 값이며, 소수점은 반올림해 표시했다.<br>실제 이동량은 기본 4%에 배율을 곱해 계산한다.
- **누적 기준:** 공격자별로 미니게임에 진입할 때마다 1회로 센다.<br>상대나 대결 결과에 관계없이 누적하고, 다음 라운드에 초기화한다.
- **최대 단계:** 세 번째 진입부터 배율은 ×1.2로 유지하며, 대결 횟수에는 제한이 없다.<br>수비 입력은 항상 ×1.0이고, 게이지 시작점은 중앙이다.

## ● 결과 처리

| 결과 | 처리와 연출 |
| --- | --- |
| 포획 | 수비자의 꼬리를 빼앗아 탈락시킨다.<br>탈락한 플레이어가 쫓던 대상을 공격자의 다음 타깃으로 지정한다.<br>공격자의 얼굴과 이름을 수비자에게 공개한 뒤 결과 화면으로 전환한다. |
| 탈출 | 공격자를 뒤로 밀어내고, 수비자는 살아남아 다시 도망칠 수 있다.<br>별도 정체 공개 연출 없이 수비자의 일반 시점으로 복귀한다. |
| 취소 | 대결 중 한쪽이 탈락하거나 사라지면 승패 확정 없이 종료한다. 이미 기록한 시도 횟수는 유지한다. |
