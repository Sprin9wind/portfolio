꼬리 잡기_저항 미니게임

● 저항 미니게임 개요

꼬리를 잡았다고 바로 승부가 끝나지는 않는다. 잡은 플레이어와 잡힌 플레이어가 C와 V를 번갈아 눌러, 최대 5초 동안 꼬리를 빼앗거나 뿌리치는 대결을 진행한다.

구분 내용
참여자 공격자는 타깃의 꼬리를 잡은 플레이어, 수비자는 꼬리를 잡힌 플레이어다.
목표 공격자는 꼬리를 빼앗아 타깃을 탈락시키고, 수비자는 잡기를 뿌리쳐 살아남는다.
조작 양쪽 모두 C부터 시작해 C → V → C 순서로 교대 입력한다. 다음에 눌러야 하는 키를 화면에서 강조한다.
시간과 판정 제한 시간은 5초다. 게이지가 한쪽 끝에 닿으면 즉시 종료하며, 시간이 끝나면 우세한 쪽이 이긴다. 중앙이면 수비자가 탈출한다.

● 설계 의도

  • 꼬리를 잡힌 뒤에도 저항할 기회를 남겨, 수비자가 마지막 순간까지 생존을 위해 행동하도록 한다.
  • 공격자의 첫 대결에서는 수비자가 뿌리치기 쉽도록 하고, 공격자가 라운드 중 대결을 거듭하면 공격 입력의 힘을 높인다. 추격이 반복되더라도 포획으로 이어질 수 있도록 한다.
  • 대결 중 수비자에게 공격자의 얼굴, 이름과 꼬리 색을 숨긴다. 탈출 시에는 별도 정체 공개 연출 없이 추격을 재개하고, 포획됐을 때 공격자를 공개한다.

● 진입 조건

항목 처리 기준
대상 자신에게 지정된 타깃의 꼬리만 잡을 수 있다.
위치와 접촉 타깃 정면 기준 후방 120° 안에서 손이 꼬리 판정에 닿아야 한다. 꼬리 판정은 본 사슬을 따라 배치한 캡슐이며, 두 캐릭터 사이를 가리는 물체가 없어야 한다.
재시도 잡기 입력마다 2초를 기다린다. 헛잡기에도 같은 대기 시간을 적용한다.
제외 상태 탈락, 대결 중, 넉백, 차량 탑승, 입력 잠금 상태에서는 시작하지 않는다.

꼬리 잡기_게이지 UI와 입력 안내

● 화면 배치

미니게임 패널은 화면 하단 중앙에 배치한다. 두 캐릭터가 보이는 중앙 영역을 가리지 않으며, 조작 키와 남은 시간, 대결의 우세를 한 패널에 모은다.

● 번호별 표시와 동작

번호 요소 표시와 변화
1 C / V 조작 키 다음에 눌러야 하는 키를 강조한다. C부터 시작하며 유효 입력이 들어오면 강조가 반대 키로 넘어간다. 눌린 상태도 함께 표시한다.
2 남은 시간 5.0초에서 시작해 남은 시간을 소수점 한 자리로 표시한다.
3 시간 막대 남은 시간의 비율을 표시한다. 처음에는 가득 차 있고, 시간이 줄어들수록 오른쪽 끝점이 왼쪽으로 이동한다.
4 우세 게이지 중앙에서 시작한다. 공격 입력은 경계점을 오른쪽으로, 수비 입력은 왼쪽으로 이동시킨다. 경계점의 위치로 어느 쪽이 우세한지 판단한다.

● 게이지와 종료 판정

경계점 위치 판정
대결 중 오른쪽 끝에 도달 공격자 승리. 즉시 포획한다.
대결 중 왼쪽 끝에 도달 수비자 승리. 즉시 탈출한다.
시간 종료 시 중앙보다 오른쪽 공격자 승리. 포획한다.
시간 종료 시 중앙 또는 왼쪽 수비자 승리. 탈출한다.

시간 막대는 얼마나 시간이 남았는지, 우세 게이지는 누가 이기고 있는지를 나타낸다. 두 막대를 위아래로 분리해 같은 정보로 읽히지 않도록 한다.

수비자 화면에서는 게이지에 표시되는 공격자 쪽 색도 숨긴다. 패널 안에 상대의 이름이나 얼굴을 추가하지 않는다.

꼬리 잡기_진행 흐름

● 시작과 승패 판정

지정된 타깃의 꼬리를 잡으면 저항 미니게임에 진입한다. 게이지가 한쪽 끝에 도달하면 즉시 판정하고, 끝에 닿지 않은 채 시간이 지나면 종료 시점의 우세로 결정한다. 중앙에서 끝났을 때는 수비자가 탈출한다.

꼬리 잡기_입력 수치와 결과 처리

● 입력과 이동량

같은 키를 연속으로 누르면 게이지에 반영하지 않는다. 다음에 요구하는 키를 눌렀을 때만 입력을 인정하며, 양쪽은 각각 자신의 다음 키를 따라 입력한다.

항목 기준 의도
제한 시간 최대 5초 잡힌 순간의 긴장을 짧은 대결로 마무리한다.
시작과 끝 내부 게이지 값은 0에서 시작하며 −1은 포획, +1은 탈출이다. 화면에는 중앙에서 양쪽 끝으로 표현한다. 우세와 종료까지 남은 거리를 전달한다.
수비 입력 유효 입력 1회당 +0.08 매 대결에서 같은 힘으로 저항할 수 있다.
공격 입력 유효 입력 1회당 −0.08 × 시도 배율 반복된 추격에 공격 측의 이점을 준다.
동시 입력 같은 프레임의 양쪽 입력량을 합산한 뒤 끝점 도달을 판정한다. 같은 가중치의 입력은 처리 순서와 관계없이 상쇄한다.

● 시도 횟수에 따른 공격 배율

공격자의 시도 배율 공격 입력 1회 이동량 의도
1회째 ×0.8 0.064 같은 속도로 입력하면 수비자가 우세하다. 첫 잡기는 뿌리칠 여지가 크다.
2회째 ×1.0 0.08 양쪽 입력의 힘이 같다. 입력 속도와 정확도로 우세를 겨룬다.
3회째 이후 ×1.2 0.096 같은 속도로 입력하면 공격자가 우세하다. 반복된 추격이 포획으로 이어지도록 한다.
  • 시도 횟수는 공격자별로 라운드 동안 누적하며, 라운드가 바뀌면 초기화한다. 수비자별 횟수나 연속 실패 횟수가 아니다.
  • 대결에 정상 진입하면 결과와 관계없이 1회를 기록한다. 헛잡기는 대결에 진입하지 않았으므로 이 횟수에 포함하지 않는다.
  • 수비 입력은 항상 ×1.0이다. 가중치는 공격 입력에만 적용하며, 시작 위치를 공격 쪽으로 옮기지 않는다.

● 결과 처리

결과 처리 연출
포획 수비자의 꼬리를 탈취하고 수비자를 탈락시킨다. 추격 사슬의 앞뒤를 다시 연결해 공격자에게 다음 타깃을 지정한다. 공격자의 얼굴과 이름을 수비자에게 공개한 뒤 결과 화면으로 전환한다.
탈출 공격자를 수비자 반대 방향으로 밀어낸다. 넉백 속도는 12, 지속 시간은 0.65초이며 수비자는 생존한다. 별도 정체 공개 연출 없이 수비자의 일반 시점으로 복귀한다.
취소 대결 중 한쪽이 탈락하거나 사라지면 결과 없이 종료한다. 이미 진입한 시도 횟수는 유지한다. 승패를 확정하지 않는다.

● 확인 범위

  • Unity 실행에서 확인: 대결 → 포획 → 정체 공개 → 결과 화면 흐름과 대결 중 공격자 정체 숨김.
  • 추가 플레이 검증: 배율 0.8 / 1.0 / 1.2가 실제 다인원 플레이에서 의도한 탈출·포획 비율을 만드는지 확인해야 한다. 제3자 개입과 접속 종료 시의 승패 규칙은 별도로 확정해야 한다.
