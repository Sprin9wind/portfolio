# 캐릭터 모션_기획 의도와 동작 설계

## ● 기획 의도

- 작은 캐릭터를 뒤에서 보더라도 달리기, 점프, 잡기 행동을 구분할 수 있어야 한다.<br>팔과 다리의 움직임을 분명하게 표현한다.
- 실제 이동과 애니메이션이 겹치지 않도록 동작은 제자리에서 재생한다.<br>캐릭터의 이동은 게임에서 처리하고, 모션은 각 행동의 자세와 리듬을 보여준다.

![달리기, 점프, 잡기의 동작 순서](../../images/whos-tail/editorial-20261019/motion-steps.svg)

## ● 모션별 기획 의도와 동작 설계

| 동작 | 기획 의도 | 동작 표현 |
| --- | --- | --- |
| 걷기 | 기본 이동을 달리기와 구분해 보여준다. | 기존 에셋의 걷기 동작을 기본 이동으로 사용한다. |
| 달리기 | 걷기와 구분되는 힘찬 추격 동작을 보여준다. | 보폭과 무릎 움직임을 크게 잡고, 팔을 몸에서 벌려 흔든다. 어깨와 골반이 서로 반대로 움직이게 한다. |
| 점프 | 도약부터 착지까지 자세의 변화를 보여준다. | 도약, 공중, 착지 자세를 구분하고, 팔과 다리의 움직임을 함께 연결한다. |
| 꼬리 잡기 | 손으로 꼬리를 낚아채는 행동이 드러나야 한다. | 오른팔을 들어 올린 뒤 아래로 뻗어 잡는다. 팔의 궤적과 손을 쥐는 동작을 연결한다. |

## ● 동작 전환 기준

| 상황 | 동작 | 연결 방식 |
| --- | --- | --- |
| 멈추거나 이동할 때 | 대기, 걷기, 달리기 | 이동 속도에 맞춰 자세를 자연스럽게 전환한다. |
| 점프하고 착지할 때 | 도약 → 상승 → 하강 → 착지 | 몸이 올라가고 내려오는 흐름에 맞춰 연결한다. |
| 꼬리를 잡으려 할 때 | 준비 → 낚아채기 → 마무리 | 잡기 입력으로 시작하고, 손이 꼬리에 닿으면 대결로 이어진다. |
| 다른 상태로 바뀔 때 | 진행 중 동작 종료 | 탈락, 탑승, 대결 시작 등으로 행동이 바뀌면 이전 잡기 동작과 예정된 접촉 판정을 취소한다. |

# 캐릭터 모션_구현 결과와 개선

## ● 제작 범위와 레퍼런스 활용

- 구매한 캐릭터 모델을 사용하고, 리그와 모션은 Blender와 AI를 활용해 제작했다.<br>걷기와 점프는 기존 에셋 동작을 활용했고, 잡기는 원본 펀치 동작을 바탕으로 수정했다.
- 후보를 정면, 측면, 후면에서 비교했다.<br>같은 조건에서 차이를 볼 수 있도록 수정 대상 외의 움직임은 유지했다.
- 영상 속 자세를 관찰해 참고했다. [마리오 달리기 영상](https://youtu.be/TW4las8Pl94)은 팔 자세 실험에,<br>[별도의 달리기 영상](https://youtu.be/SBw43XmHzg0)은 최종 달리기 후보 제작에 활용했다.

![달리기 레퍼런스에서 비교한 팔 자세](../../images/whos-tail/editorial-20261019/reference-motion.svg)

- 첫 시안이 팔을 접은 가속 후 자세로 만들어져, 팔을 옆으로 벌린 가속 전 자세로 수정을 요청했다.<br>이 팔 자세 실험은 Blender 단계에서 마쳤다.

## ● 후보 비교와 선택

| 동작 | 비교 기준 | 선택과 수정 |
| --- | --- | --- |
| 달리기 | 레퍼런스 영상의 어깨 움직임, 보폭과 팔 흔들기 | 레퍼런스 영상을 기준으로 어깨 움직임과 보폭을 보완했다. 무릎 높이와 뒤꿈치가 올라오는 동작도 조정했다. |
| 점프 | 원본의 이동 궤적을 유지한 상태에서 팔 자세 비교 | 원본 점프를 바탕으로 팔 동작 후보를 비교해 최종 동작을 선택했다. 하체 움직임은 유지했다. |
| 꼬리 잡기 | 손의 궤적이 꼬리를 잡는 행동으로 읽히는지 | 원본 펀치의 타이밍과 손 쥐기를 살리고, 오른팔을 위에서 아래로 낚아채도록 바꿨다. |
| 걷기 | 새 시안과 원본의 움직임 비교 | 원본이 더 적합하다고 판단해 유지했다. 제자리 재생, 발 높이와 반복 구간의 연결을 정리했다. |

## ● 발견한 문제와 개선 내용

| 발견한 문제 | 수정 방향과 결과 |
| --- | --- |
| Blender와 Unity에서 자세가 달라짐 | Humanoid 리타게팅 설정을 점검했다. Unity에서 Generic 설정으로 가져온 모션을 기존 캐릭터에 적용했다. Blender 시안과 비교한 주요 자세에서 같은 모습임을 확인했다. |
| 기존 캐릭터 제어와 제작 모션을 함께 사용해야 함 | 기존 애니메이션 제어는 유지하고, 별도 리그에서 재생한 자세를 캐릭터에 전달하도록 연결했다. |
| 달리기 미리보기가 중간에서 끊김 | 반복 동작을 끝까지 재생하도록 미리보기 범위를 수정했다. 동작 속도는 유지했다. |
| 잡기 동작 수정이 다른 부위에 영향을 줄 수 있음 | 오른팔의 움직임만 수정하고, 비교한 자세에서 몸통과 다른 팔다리의 자세가 바뀌지 않았음을 확인했다. |

- 팔 자세를 비교한 초기 실험과 최종 달리기 제작은 별도로 진행했다.
