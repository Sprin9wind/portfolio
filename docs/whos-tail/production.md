# 3.1 캐릭터 모션 제작 기준

## ● 공통 방향

- 캐릭터를 뒤에서 보는 추격 게임에 맞춰 팔, 다리의 동작 차이가 읽히도록 구성.
- 구매 에셋의 모델, 리그, 기본 모션을 활용하고, 플레이에 필요한 동작만 수정.
- 캐릭터의 실제 이동은 게임 코드가 담당. 애니메이션은 제자리 재생을 기준으로 작업.

![달리기, 점프, 꼬리 잡기의 동작 스케치](../../images/whos-tail/specs/motion-plan.svg)

*달리기, 점프, 잡기 동작의 자세와 움직임 방향을 정리한 스케치.*

| 동작 | 요구사항 | 작업 범위 |
| --- | --- | --- |
| 걷기 | 반복 연결이 자연스럽고 발이 바닥을 관통하지 않음 | 기본 모션 유지, 제자리, 루프 정리 |
| 달리기 | 짧은 다리에서도 보폭과 무릎 회수가 보임 | 어깨, 팔 움직임, 무릎 높이, 뒤꿈치 회수 조정 |
| 점프 | 상승과 하강의 차이가 보이고 팔이 과하게 흔들리지 않음 | 원본 점프를 기준으로 팔 자세, 균형 동작 조정 |
| 꼬리 잡기 | 낮은 위치의 꼬리를 위에서 아래로 낚아챔 | 원본 펀치의 오른팔 궤적 수정 |

## ● 원본 보존 및 비교 조건

1. 원본 액션은 보존하고 별도 작업본에서 수정.
2. 점프의 팔 동작 후보는 궤적, 타이밍, 다리 동작을 고정하여 비교.
3. 정면, 측면, 후면을 함께 확인한 뒤 후보 선택.
4. 선택 후 단일 캐릭터로 반복 재생하여 루프 경계와 바닥 접촉 확인.

*달리기 C안의 미리보기 범위가 12프레임 주기를 중간에 끊는 문제가 있었음. 속도나 모션을 바꾸지 않고 재생 범위를 완전한 주기로 조정.*

# 3.2 레퍼런스 분석 및 적용 기준

## ● 영상 레퍼런스의 사용 범위

![마리오 달리기 참고 영상의 가속 전과 가속 후 자세 비교](../../images/whos-tail/specs/reference-motion.svg)

*참고용 화면: [마리오 달리기 참고 영상, 14~19초](https://youtu.be/TW4las8Pl94?t=14). 오른쪽은 각 프레임의 캐릭터 부분 확대.*

| 구분 | 확인 항목 |
| --- | --- |
| 관찰 | 약 15.7초의 가속 전후로 팔 형태가 달라짐. 프레임 시트로 두 상태를 분리 |
| 적용 대상 | 가속 전의 팔을 벌린 자세. 큰 머리와 짧은 다리의 캐릭터 비율에 맞게 조정 |
| 사용 범위 | 마리오 참고 시안은 자세 비교 실험. 최종 달리기는 별도 레퍼런스와 A~D 후보 비교 후 C안 선택 |

## ● AI 요청 및 수정 기준

- **입력:** 캐릭터, 원본 액션, 참고 구간을 지정. 원하는 팔 형태는 정정 요청으로 구체화.
- **비교 조건:** 리그, 하체, 재생 속도는 유지. 팔 수정 전후를 동일한 시점으로 비교.
- **재요청:** 가속 후 자세로 해석된 시안을 가속 전 자세로 정정. 프레임 시트의 관찰 결과를 기준으로 수정 범위를 한정.

## ● Unity 적용 검수

| 확인 대상 | 판정 기준 |
| --- | --- |
| 자세 일치 | Humanoid 리타게팅으로 승인 자세가 달라진 문제 확인. Generic 리그로 다시 내보내고 Blender와 Unity의 표본 자세 대조 |
| 상태 전환과 루프 | 상태별 클립, 반복 지점의 자세 튐, 발 미끄러짐 확인 |
| 부분 수정 | 잡기 동작에서 오른팔 외의 원본 동작이 유지되는지 확인 |
| 게임 화면 | 실제 카메라 거리에서도 동작과 꼬리 위치가 구분되는지 확인 |

*영상 관찰을 자세 설계에 활용하며 정밀 모션 캡처로 간주하지 않음. 엔진 검수는 최종 선택한 클립을 대상으로 진행.*
