AI 검증 결과 보고서WHO’S TAIL / 01

꼬리에 닿았는데 잡히지 않는 이유 확인

기획자의 요청에 따라 AI가 반복 테스트를 수행하고, 발견한 문제와 수정 결과를 보고합니다.

요청 목적

기획자는 손이 꼬리에 닿아 보이는데 잡히지 않는 상황을 찾고, 잡기 반응을 확인해 달라고 요청했습니다.

확인할 결과

거리, 방향, 속도를 바꾸며 접촉과 대결 진입을 기록했습니다. 대결 진입은 꼬리를 잡은 뒤 서로 겨루는 단계가 시작되는 것입니다.

01 / 어떻게 테스트했는가

실제 캐릭터, 동작, 판정 코드를 쓰는 별도 테스트 공간에서 AI가 이동과 잡기를 자동으로 반복했습니다. 실행과 독립 검토를 나눠 로그, 화면, 코드 변경을 대조했습니다.

구분조건과 확인 내용
수정 전후 각 40회함께 걷기, 함께 달리기, 멀어지기, 뒤쫓기, 회전하기 5종
× 시작 간격 0.7 / 1.0 / 1.3 / 1.6m × 각 2회
추가 검증 72회새 간격과 회전 시점, 두 캐릭터, 벽과 방향 및 행동 제한을 확인.
대결이 시작되면 안 되는 66회와 회전 조건 6회로 구성
기록과 판단잡기 버튼 입력과 실제 대결 진입을 구분하고, 캐릭터의 위치와 속도, 손과 꼬리가 가까워지는 시점을 대조

간격은 시작 시 캐릭터 사이 거리입니다. 같은 설정을 반복해도 매 순간의 자세가 완전히 같지는 않습니다.

02 / 무엇을 발견했는가

회전 조건에서는 손과 꼬리가 가까워진 뒤 상대가 돌아섰고, 기존 판정 시점에는 잡기 조건을 벗어났습니다.

동작 중 한 번만 확인하던 방식이 짧은 접촉을 놓칠 수 있었습니다.

03 / 무엇을 수정했는가

게임 수정 담당자가 보이는 꼬리 형태를 반영하고, 잡기 동작 중 접촉 확인을 추가했습니다.

확인 시점잡기 도중에도 확인

동작 시작 0.25초부터 기존 판정 직전까지 접촉을 확인합니다.

접촉 범위꼬리 모양 반영

두 캐릭터의 꼬리 모양에 가까운 범위를 두고, 현재 손끝이 닿는지 확인합니다.

기존 제한거리와 방향 유지

사거리, 뒤에서 잡는 조건, 시선과 장애물 제한을 유지했습니다.

기존 사거리와 꼬리의 허리 쪽을 제외하는 규칙은 그대로입니다. 현재 접촉만 확인하며, 이미 멀어진 상대를 과거 접촉만으로 잡지는 않습니다.

수정 후 어떤 결과가 나왔는가

같은 조건으로 다시 실행해 대결 진입 여부와 시점, 기존 제한의 유지 여부를 확인했습니다.

시작 간격 1.0m, 회전 조건, 수정 전후 각 2회
0/2회 → 2/2회대결 미진입 → 진입

수정 전후 각 40회 중 이 조건의 2회에서 진입 여부가 바뀌었습니다. 특정 조건의 소규모 비교 결과입니다.

04 / 수정 후 재검증 결과

검증 항목확인한 결과
나머지 38회대결 진입 여부는 같았습니다. 함께 걷는 0.7m 조건은 진입 시점이 약 0.60초 → 0.25초로 앞당겨졌습니다.
추가 검증 72회대결이 시작되면 안 되는 66회에서 진입 0회였습니다. 나머지 회전 조건 6회는 별도 관찰로 두었습니다. 이 72회에는 수정 전 비교가 없어 개선 집계에 넣지 않았습니다.
중복과 재입력추가 72회에서 대결이 중복 생성된 경우 0회, 대결 중 잡기 재입력이 받아들여진 경우 0회였습니다.
계산 간격을 늘린 경우1초에 20번 계산하는 조건(20Hz)에서는 1.0m 회전의 접촉 누락이 남았습니다. 화면 표시 속도를 잰 결과는 아닙니다.

05 / 실제 맵에서도 흐름 확인

실제 맵은 자동 입력으로 범위 밖 미진입, 대결 시작, 재입력 거절을 점검했습니다. 추가한 접촉 검사의 실행 여부까지 구분한 기록은 아닙니다.

기획자에게 보고하는 결론

1.0m 회전 조건의 접촉 누락을 재현했고, 수정 후 2회 모두 대결 진입을 확인했습니다. 기존 사거리는 유지했습니다.

추가 66회도 기대한 미진입을 유지했습니다. 전체 정확도, 조작 만족도와 재미의 변화는 측정하지 않았습니다.

후속 확인

20Hz 접촉 누락과 0.7m 회전의 변동은 남아 있습니다. 온라인 지연과 여러 PC, 직접 플레이의 조작감과 재미, 다른 지형과 아이템 조합은 후속 확인 대상입니다.
