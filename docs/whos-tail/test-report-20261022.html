보이는 접촉과 잡기 반응을 맞추기

반복 플레이 테스트로 접촉 누락 조건을 찾고, 실제 게임 판정을 보완했습니다.

확인하고자 한 경험

손이 꼬리에 닿아 보이는 순간에도 잡히지 않는 조건을 찾고, 화면에서 예상한 반응과 실제 대결 진입을 맞추고자 했습니다.

제가 AI에 요청한 내용

두 캐릭터의 거리·방향·속도를 바꿔 반복 실행하고, 손끝·꼬리 위치와 접촉 시점, 대결 진입을 함께 기록하도록 요청했습니다.

01 / 테스트 방법

실제 캐릭터·모션·판정 코드를 사용하는 별도 테스트 씬에서 AI가 입력과 기록을 자동화했습니다. Orca로 실행과 독립 검토를 나눠 로그·화면·코드 변경을 대조했습니다.

구분조건과 확인 내용
수정 전후 각 40회걷기 동행·달리기 동행·이탈·추격·회전 5종 × 초기 간격 0.7 / 1.0 / 1.3 / 1.6m × 2회
추가 검증 72회새 간격·회전 시점과 두 캐릭터, 벽·방향·상태 제한을 확인. 미진입 기대 66회와 회전 관측 6회를 구분
결과 판단 기준잡기 동작 접수와 대결 진입을 분리 기록. 실제 위치·속도·손끝 접촉을 함께 대조

거리 수치는 시작 시 캐릭터 간 간격입니다. 같은 설정을 반복했지만 프레임·포즈가 완전히 동일한 결정론적 재생은 아닙니다. 기본 시뮬레이션 간격은 1/60초입니다.

02 / 발견한 문제

상대가 회전하면 손이 꼬리에 가까워진 뒤, 기존의 한 차례 판정 시점 전에 접촉 조건에서 벗어나는 경우가 있었습니다.

기존 지연 판정만으로는 동작 중 잠깐 발생하는 접촉을 놓칠 수 있었습니다.

03 / 실제 게임 판정 보완

접촉 시점동작 중 추가 확인

잡기 시작 0.25초 이후부터 기존 판정 직전까지, 현재 손끝과 꼬리 접촉을 검사합니다.

판정 형태보이는 폭·두께 반영

꼬리 방향을 따르는 띠 형태에 반폭 0.06m, 반두께 0.035m와 손끝 반경 0.03m를 적용했습니다.

유지할 조건사거리·제한 유지

기존 사거리 0.9m와 보정 0.25m, 허리 쪽 제외 35%, 후방·시선·장애물 제한을 유지했습니다.

두 캐릭터의 측정한 꼬리 형태를 근사한 판정입니다. 모션과 꼬리 갱신 후 실제 손가락 끝 10곳을 검사하며, 과거 접촉을 저장해 소급 판정하지 않습니다.

회전 중 놓치던 접촉의 반응 개선

전체 성공률 대신, 같은 재현 조건의 수정 전후와 제한 조건을 구분해 확인했습니다.

초기 간격 1.0m · 회전 조건의 대결 진입
0/2회 → 2/2회2회 모두 미진입 → 진입

수정 전후 각 40회에서 해당 회전 조건 2회만 결과가 바뀌었습니다. 작은 표본의 특정 조건 결과이며, 전체 정확도나 일반적인 성공률 개선을 뜻하지 않습니다.

04 / 재검증 결과

검증 항목결과와 해석
나머지 38회 비교대결 진입 여부는 동일. 다만 0.7m 걷기 동행은 진입 시점이 약 0.60초 → 0.25초로 앞당겨졌습니다.
추가 제한 조건 66회미진입 기대 66회에서 진입 0회. 나머지 6회는 0.85m에서 회전 전 3회 진입, 1.15m에서 3회 미진입. 수정 전 비교가 없어 개선 집계에서는 제외했습니다.
중복 진입·재입력추가 72회에서 대결 중복 생성 0회, 대결 중 잡기 재입력 접수 0회.
20Hz 시뮬레이션1.0m 회전 조건 0/2회 진입으로 짧은 접촉 누락은 미해결. 수정 전 비교는 없으며 FPS·성능 측정이 아닙니다.

05 / 실제 맵과 대결 흐름 확인

실제 맵은 범위 밖 미진입·대결 진입·재입력 거절을 확인한 통합 점검입니다. 새 접촉 검사 경로의 실행 여부를 구분한 결과나 직접 플레이 기록은 아닙니다.

결론 / 놓치던 접촉을 반영하고, 제한은 유지

회전 중 접촉을 놓치던 2회가 모두 대결 진입으로 이어졌습니다. 사거리를 일괄적으로 늘리지 않고 접촉 형태와 검사 시점을 보완해, 이번 자동 테스트에서 놓치던 회전 접촉을 판정에 반영했습니다.

남은 확인

온라인 지연·다중 PC, 직접 플레이의 조작감과 재미, 모든 지형·아이템 조합은 미검증입니다. 0.7m 회전은 프레임 경계에 따라 결과가 달라 개선 집계에서 제외했습니다. 20Hz에서 남은 접촉 누락도 후속 검증 대상으로 남겼습니다.
