마무리기본 점프의 착지 동작

연출 개요

  • 기본 점프 중 공중에서 한 바퀴 더 회전하는 동작이다. 회전은 한 번 재생하고, 마무리는 기본 점프의 착지 동작으로 이어진다.
  • 공중 회전 애니메이션에 먼지와 구름 형태의 잔상 이펙트를 조합한다. 사운드는 기본 점프와 동일한 리소스를 사용한다.

동작 구성

단계 애니메이션
준비 기본 점프 동작 상태에서 이어진다.
액션 공중에서 한 바퀴 더 회전한다. 한 번 재생하며 길이는 400ms다.
마무리 기본 점프의 착지와 동일한 동작을 사용한다.

리소스 구성

구분 리소스명 내용 반복 / 시간
애니메이션 Player_DoubleJump_Anim 공중 회전 동작 1회 / 400ms
이펙트 Player_DoubleJump_Effect 더블 점프 시 먼지와 구름 형태의 잔상이 남는 효과 1회 / 200ms
사운드 Player_Jump_sound 기본 점프와 동일한 사운드 사용 1회 / 200ms

효과와 사운드

  • 이펙트는 먼지와 구름 형태의 잔상으로 표현하며, 한 번 재생한다. 재생 시간은 200ms다.
  • 사운드는 기본 점프와 동일한 Player_Jump_sound를 사용한다. 한 번 재생하며 재생 시간은 200ms다.
