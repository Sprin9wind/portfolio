캐릭터 동작과 연출 전달

● 동작을 제작 단위로 나누기

  • 더블 점프, 기본 공격, 패링, 슬라이딩 등 주요 동작의 애니메이션, 이펙트, 사운드를 정의한다.
  • 동작을 준비 → 액션 → 마무리로 나눠 시작과 종료 자세를 연결한다. 각 구간에 필요한 리소스, 반복 여부, 재생 시간을 작성한다.
  • 참고 이미지와 영상은 동작의 방향을 설명하는 자료로 사용하고, 실제 제작할 리소스의 이름과 규격은 별도로 명시한다.

● 더블 점프의 움직임

단계 애니메이션 지시
준비 기본 점프 동작 상태에서 이어진다.
액션 공중에서 한 바퀴 더 회전한다. 한 번 재생하며 길이는 400ms다.
마무리 기본 점프의 착지와 동일한 동작을 사용한다.

● 같은 동작에 필요한 리소스

구분 리소스명 내용 반복 / 시간
애니메이션 Player_DoubleJump_Anim 공중 회전 동작 1회 / 400ms
이펙트 Player_DoubleJump_Effect 더블 점프 시 먼지와 구름 형태의 잔상이 남는 효과 1회 / 200ms
사운드 Player_Jump_sound 기본 점프와 동일한 사운드 사용 1회 / 200ms

● 제작 요청에 포함할 정보

항목 전달 목적
시작과 종료 자세 앞뒤 동작을 연결할 기준을 제공한다.
동작 설명 어떤 움직임을 표현해야 하는지 구체화한다.
리소스명 제작 파일과 게임에서 사용할 대상을 대응시킨다.
반복 여부와 재생 시간 반복 동작과 일회성 동작을 구분하고 길이를 맞춘다.
참고 이미지와 영상 움직임, 잔상, 분위기의 방향을 공유한다.

● 기획과 제작의 역할

동작의 구성과 제작 기준을 기획해 아트 작업에 전달한다. 완성된 애니메이션 초안은 팀의 제작 결과로 구분하고, 기획한 동작과 연결되는지 확인하는 자료로 사용한다.
