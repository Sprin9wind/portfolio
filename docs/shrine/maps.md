# 마을의 역할과 배치 기준

## ● 신당 운영과 던전 탐험을 잇는 공간

- 신당에서 망자를 상담하며 성장하고, 성장한 캐릭터로 플랫포머 던전을 진행하는 구조다.
- 마을은 구매, 타이쿤 진입, 이야기 진행, 퀘스트 수락, 던전 입장을 담당하는 시설을 한 공간에 배치한다.

## ● 시설별 기능

| 시설 | 플레이어가 이용하는 기능 | 리소스명 |
| --- | --- | --- |
| 상점 | 재화와 소모품 구매 | Adv_Town_Shop |
| 흥신소 | 타이쿤 진행 공간으로 진입 | Adv_Town_TaycoonEntry |
| 저승 재판소 | 스토리 관련 진행 | Adv_Town_Tribunal |
| 퀘스트 알림판 | 메인 퀘스트와 서브 퀘스트 수락 | Adv_Town_Questboard |
| 저승 관문 | 던전, 메인 퀘스트 입장 | Adv_Town_Gateway |

## ● 크기와 화면 배치

- 마을의 가로 길이는 40m, 걷기 이동 속도는 2m/s를 기준으로 잡는다. 단순 직선 이동으로는 약 20초이며, 마을 전체 이동 시간은 20~25초를 기준으로 기획한다.
- 건물과 플레이어 사이에는 충돌을 두지 않는다.
- 레이어는 **배경 → 건물 → 바닥 타일과 플레이어** 순으로 구성한다.
- 아트 요청에는 리소스명, 대략적인 작업 크기, 캐릭터 대비 가로와 세로 비율을 함께 전달한다.

## ● 시설의 기능을 드러내는 외형

| 시설 | 디자인 방향 |
| --- | --- |
| 흥신소 | 무너지기 직전의 기와집, 성불 기원 현수막과 거미줄 |
| 저승 재판소 | 큰 문과 웅장한 외관, 조선시대 성문을 연상시키는 형태 |
| 상점 | 트럭과 마차를 연상시키는 판매대, 위에 놓인 호리병과 부적 |
| 퀘스트 알림판 | 기와지붕과 나무 몸체, 가운데 붙은 낡은 종이 |

시설의 용도와 외형을 함께 정의해 기능 배치와 아트 제작이 같은 공간 구성을 기준으로 진행되도록 한다.

# 탐험 동선과 구역별 장치

## ● 연결된 구역을 돌아 막힌 통로를 여는 구조

- 챕터 1은 A1~A6을 순서대로 연결한다. A6의 레버를 작동하면 A1의 통로를 막던 벽이 올라간다.
- 몬스터 배치, 이동 발판, 함정, 레버를 구역별로 정의해 이동과 전투의 조건을 구분한다.

<div class="flow"><div>A1<br><small>진입 / 막힌 통로</small></div><b>→</b><div>A2</div><b>→</b><div>A3</div><b>→</b><div>A4<br><small>철퇴 함정</small></div><b>→</b><div>A5<br><small>이동 발판</small></div><b>→</b><div>A6<br><small>레버 작동</small></div></div>
<p class="return-line">A6 레버 작동 → A1의 막힌 벽 상승</p>

## ● 장치별 작동 조건

| 구역 | 장치 | 동작과 조건 |
| --- | --- | --- |
| A1 | 통과 가능한 발판 | 발판 위에서 점프와 아래 방향키를 함께 입력하면 아래로 통과한다. |
| A1 | 통로를 막은 벽 | 처음에는 통로를 막는다. A6 레버를 누르면 벽이 올라간다. |
| A4 | 철퇴 함정 | 철퇴 부분에 피격 판정을 둔다. 연결된 쇠사슬에는 충돌 판정을 두지 않는다. |
| A5 | 1번 이동 발판 | 위아래로 계속 왕복한다. |
| A5 | 2번 이동 발판 | 위쪽에 고정돼 있다가 A5의 몬스터를 모두 처치하면 위아래로 움직인다. |

## ● 탐험과 전투가 연결되는 지점

- A1에서는 통과 가능한 발판과 통로의 차단 상태를 구분한다. 길이 막혀 있는 이유를 레버 작동과 연결한다.
- A4에서는 피해를 주는 철퇴와 충돌하지 않는 쇠사슬을 분리해 함정의 판정 범위를 정한다.
- A5에서는 항상 움직이는 발판과 전투 후 활성화되는 발판을 구분한다. **몬스터 처치가 다음 이동 수단을 여는 조건**이 된다.

## ● 배치 문서의 전달 항목

| 항목 | 문서에 표시할 내용 |
| --- | --- |
| 연결 | 구역 사이 연결부와 진입 위치 |
| 몬스터 | 종류별 배치 영역과 구분 기호 |
| 발판 | 통과 여부, 이동 방향, 시작 조건 |
| 장치 | 조작 위치와 영향을 받는 대상 |
| 판정 | 피해 또는 충돌이 적용되는 부분 |

지도상의 위치만 제시하지 않고, 각 장치가 언제 어떤 상태로 바뀌는지 함께 명시한다.
