# 몬스터_데이터와 등급별 공략
## ● 기본값과 전투 규칙을 나누어 관리

<div class="data-flow"><b>MonsterTB<br><small>개체의 스탯, 커맨드, 패턴, 드롭</small></b><span>→</span><div><p>MonAtkPatternTB, 공격 효과</p><p>MonToPlayerSeTB, 상태이상</p><p>DropTB, 보상 구성</p></div></div>

| 데이터 | 관리하는 항목 |
|---|---|
| MonsterTB | 레벨 1 스탯, 수명, ATB 속도, 약점 커맨드 3개, 공격 패턴 3개, 드롭 ID |
| MonAtkPatternTB | 피해 배율, 방어 무시, 흡수 비율, 상태이상 연결 |
| MonToPlayerSeTB | 대상 스탯, 효과량, 지속 턴, 피격 해제, 중첩 여부 |
| DropTB | 장비와 재료 등 보상 구성과 드롭 확률 |

## ● 등급에 따라 공략을 이어 간다

| 등급 | 활성 커맨드 | 전환 규칙 |
|---|---|---|
| Normal | 3개 중 무작위 1개 | 전투 중 고정 |
| Elite | 3개 중 무작위 2개 | 첫 커맨드 공략 후 두 번째로 전환 |
| Boss | 3개 모두 | 1 → 2 → 3 순차 전환 |

## ● 개체 생성, 공격, 보상

- ID는 **지역 1자리 + 등급 1자리 + 고유 번호 3자리**다. 예: 10001.
- 스탯의 기본 계산은 **기본값 × (1 + (레벨 − 1) × 0.1)**이다. 현재 시뮬레이터는 HP, ATK, DEF, 수명에 적용한 뒤 소수점을 버리고, ATB 속도는 원래 값을 사용한다.
- ATB 100%에서 지정된 공격 패턴 3개 중 1개를 무작위 실행한다. 기본 공격 외 강공, 중독, 출혈, 약화, 둔화, 흡수, 혼란, 수면, 축소를 구성한다.
- 같은 상태이상은 더 긴 지속 턴으로 갱신하고, 다른 상태이상은 동시에 적용한다. **플레이어의 행동 게이지 슬롯이 찰 때 1턴**으로 센다. 중첩 여부는 상태별 정의를 따른다.
- **처치 시 획득 수명 = 몬스터 초기 수명 − 전투 중 몬스터가 소모한 수명.** 늦게 처치할수록 남아 있는 보상이 줄어드는 구조다.

<div class="note">현재 시뮬레이터는 선택한 커맨드 번호로 고정한다. 등급별 전환과 상태이상 지속, 갱신, 중첩은 구현되어 있지 않아, 해당 규칙의 효과를 측정한 결과로 볼 수 없다.</div>
