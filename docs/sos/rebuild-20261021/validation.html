  • ATB 시뮬레이터는 MonsterTB를 읽어 전투를 재현하는 검증 도구다. 이 쪽의 구현값은 앞 쪽의 기획 규칙을 대체하지 않는다.

검증_비교 계획과 미결 수치

  • 검증할 가설: 약점을 빠르게 찾아 처치한 전투가, 무작위로 공격한 전투보다 수명 손익이 좋아야 한다.
  • 아래는 앞으로 수행할 계획이며 측정 결과가 아니다.

● 수명 손익

수명 손익 = 실제 흡수량 − 시간 소모 − 긴급 행동 비용같은 수명 단위로 환산한다. 긴급 비용이 포함된 총소모를 썼다면 다시 빼지 않는다.

계산 예시: 승리해 100을 흡수하고 시간에 20, 약점 파악에 10을 썼다면 손익은 +70이다.

● 측정 전 조건

  1. 데이터 시트의 행과 열이 올바르게 읽히는지 원본 표와 대조한다.
  2. 수명 단위, 소모율, 반올림, 긴급 비용, 성공 기록의 재사용 범위를 정한다.
  3. 승패별 보상 계산을 나누고 미구현 규칙은 비교에서 뺀다.
  4. 적 패턴 선택과 반복 횟수를 기록한다. 현재 난수 시드는 고정할 수 없다.

● 자료마다 다른 수치

초기 기획은 일(日) 단위로 시작 수명 60년(21,900일), 일반 300~400일, 엘리트 500~1,000일, 중간보스 3,000일을 기준으로 삼았다. 아래는 확정 규칙이 아니다.
