# SOS 기획서

전투 시스템, 몬스터 데이터, 검증 계획을 분리한 최신 읽기용 문서다. 외계인 노동자와 메이플 배틀 아레나 기획서의 제목 막대, 규칙 표, 번호 주석, 조건별 예시 형식을 참고했다.

| 문서 | 범위 | 쪽수 |
| --- | --- | --- |
| [전투](battle.html) | 핵심 구조, 화면 구성, 행동 예약과 긴급 행동, 피해 규칙, 약점 커맨드 | 5 |
| [몬스터](monster.html) | 데이터 연결과 등급 운용, 공격 효과·상태이상·보상 | 2 |
| [검증](validation.html) | 기획과 구현의 차이, 비교 계획과 미결 수치 | 2 |

포트폴리오 이미지: `images/sos-specs/rework-20261022/`의 A4 9쪽. 이전 `design-20261021/` 이미지는 보존된 이전 버전이다.

기획 규칙은 원문 전투 기획서와 UI 와이어프레임, 데이터 입력값은 `MonsterTB_1.2.xlsx`를 기준으로 정리했다. 시뮬레이터의 다른 공식과 미구현 규칙은 검증 문서에서 구분한다. 미결 수치와 검증 계획은 확정값이나 실측 성과로 취급하지 않는다.

HTML과 같은 이름의 Markdown은 동일 원고다. 이미지의 팀 제작 출처 표기를 유지한다.
