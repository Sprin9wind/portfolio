컨셉 기획_하차 미니게임 플레이 루프

플레이 목표

  • 택배차에서 내려온 택배를 배송지역이 같은 컨베이어 벨트로 옮겨, 제한 시간 60초 안에 높은 스코어를 얻는 미니게임입니다.

  • 단순한 운반 반복에 그치지 않도록 세 가지 판단을 겹쳤습니다.

  • 얼마나 들까: 한 번에 여러 개를 들면 이동 횟수가 줄지만, 든 무게만큼 느려진다. 무거운 택배일수록 바르게 놓았을 때 점수가 크다.

  • 어디에 놓을까: 송장 라벨의 배송지역과 벨트의 배송지역이 맞으면 점수를 얻고, 틀리면 점수를 잃는다.
  • 어떤 순서로 놓을까: 취급 주의 택배는 여러 개를 들었을 때 반드시 마지막에 놓아야 한다.

한 판의 진행 순서

단계 플레이어 입력 시스템 처리
자동 하차 없음 3초마다 택배 1개를 하차 영역에 쌓고, 미리보기를 다음 택배로 바꾼다.
택배 들기 하차 영역에 다가가 상호작용 버튼(PC: Space) 하차 영역의 가장 위 택배를 든다.
운반 조이스틱(PC: W, A, S, D) 이동 가능 영역 안에서 X, Y축으로 자유롭게 움직인다. 든 무게만큼 느려진다.
택배 놓기 배치 영역에 다가가 상호작용 버튼(PC: Space) 든 택배 중 가장 위의 택배를 벨트에 올리고 스코어를 계산한다.
종료 없음 타이머가 0이 되면 즉시 끝내고 결과창을 연다.

화면 구성 요소

요소 역할
하차 택배 미리보기 다음에 하차될 택배의 정보와 하차까지 남은 시간을 보여 준다.
타이머 게임 종료까지 남은 시간을 표시한다.
스코어 보드 현재까지 얻은 누적 점수를 표시한다.
옵션 버튼 화면 오른쪽 위에 둔다. 세부 기능은 따로 설계한다.
하차 완료 택배 자동 하차된 택배가 쌓이는 영역으로, 최대 5개까지 쌓인다.
이동 조이스틱, 상호작용 버튼 모바일 조작 UI다. PC에서는 키보드로 대신하고 화면에 표시하지 않는다.

컨셉 기획_택배 생성과 자동 하차

택배 오브젝트 구성

  • 택배는 생성될 때 아래 세 값을 받습니다.
  • 송장 라벨에는 Region에 따른 배송지역과 FlagileIsTrue에 따른 취급 주의 표시가 나타납니다.
컴포넌트 자료형 규칙
Weight Int 1, 3, 5, 10 중 하나를 같은 확률로 받는다. 무게에 따라 우편(1Kg), 소형(3Kg), 일반(5Kg), 대형(10Kg) 택배로 외형이 달라진다.
Region String 수도권, 충청권, 영남권, 호남권, 강원권 중 하나를 같은 확률로 받는다.
FlagileIsTrue bool True(취급 주의 택배) 20%, False(일반 택배) 80% 확률로 정해진다.

자동 하차 규칙

  • 택배는 3초마다 자동으로 하차되어 하차 영역에 순서대로 쌓인다.
  • 하차 영역에는 최대 5개까지 쌓인다. 5개가 차 있으면 3초가 지나도 하차하지 않는다.
  • 하차에 성공하면 미리보기가 다음 택배로 바뀌고 타이머가 3.0초로 초기화된다.
  • 하차 영역이 가득 차 실패하면 미리보기의 택배를 그대로 두고, 다음 하차가 이뤄질 때까지 타이머를 0.0초로 유지한다.

미리보기 표시 방식 수정

  • 초기안은 미리보기 테두리를 따라 시간 게이지가 차오르는 방식이었습니다.
  • 수정안에서는 테두리 게이지 대신 미리보기 안에 송장 번호, 배송지역, 구분(무게)을 글자로 적고 아래에 남은 시간을 초 단위 숫자로 표시합니다.

예외: 우편

  • 우편(Weight 1)은 미리보기에서는 배송지역을 확인할 수 있지만, 하차 영역에는 눕혀진 채 쌓여 라벨이 보이지 않습니다.
  • 미리보기에서 본 배송지역을 기억해야 하는 난이도 조절 요소이며, 플레이 결과에 따라 뺄 수 있는 규칙으로 두었습니다.

컨셉 기획_들기, 운반, 놓기 판정

상호작용 버튼 상태

하나의 상호작용 버튼이 캐릭터의 위치와 들고 있는 택배에 따라 기능을 바꿉니다.

상태 조건 입력 결과
비활성 하차 영역과 배치 영역 어디에도 인접하지 않음 반응하지 않는다.
택배 들기 하차 영역의 택배에 인접 가장 위의 택배를 든다. 더 들 택배가 없으면 다시 비활성화된다.
택배 놓기 배치 영역에 인접하고 택배를 들고 있음 들고 있는 가장 위의 택배를 벨트에 올린다. 든 택배가 없으면 배치 영역에 인접해도 활성화되지 않는다.

운반 무게와 이동속도

  • 캐릭터가 한 번에 들 수 있는 무게는 최대 10Kg이다.
  • 든 무게 1Kg마다 이동속도가 2% 줄어, 10Kg을 들면 20% 느려진다.

배치 판정과 스코어

상황 스코어 변화
택배와 벨트의 배송지역 일치 택배 무게 × 10점 획득
택배와 벨트의 배송지역 불일치 택배 무게 × 5점 감소
취급 주의 택배를 마지막 순서가 아닐 때 놓음 택배 파손. 배송지역과 관계없이 50점 감소
  • 스코어는 0점 아래로 내려가지 않는다.
  • 취급 주의 택배를 다른 택배와 함께 들었다면 반드시 마지막에 놓아야 한다. 놓는 순간 캐릭터에게 남은 무게가 0Kg이 아니면 파손으로 처리하고, 배송지역에 따른 획득이나 감소는 적용하지 않는다.

컨셉 기획_이동 영역과 UI 규격

전체 영역과 인게임 뷰

  • 전체 맵은 가로 2360이며, 위쪽 420은 이동할 수 없는 배경, 아래쪽 1040은 이동 가능 영역입니다.
  • 화면에는 이 중 1920 × 1080 범위가 표시됩니다.

게임 종료

  • 타이머가 0이 되면 즉시 게임을 끝내고 결과창을 띄운다.
  • 결과창에는 해당 판의 최종 스코어를 표시한다.

UI 표시 형식과 리소스 크기

  • 1920 × 1080 화면을 기준으로 각 요소의 크기와 표시 형식을 정했습니다.
  • 리소스 크기는 각 ±30까지 허용합니다.
요소 크기 표시 규칙
하차 택배 미리보기 512×320 송장 번호는 알파벳 3자, 하이픈, 숫자 4자리의 무작위 조합(예: AXC-3049)이다. 배송지역과 구분은 택배 컴포넌트 값을 그대로 쓰고, 취급 주의 여부는 글자로 쓰지 않는다. 남은 시간은 소수 첫째 자리까지 표시한다.
타이머 400×110 00:00 형식으로 소수 둘째 자리까지 표시한다.
스코어 보드 350×100 Score : xxxx 형식으로 최대 4자리까지 표시한다.
이동 조이스틱 256×256 왼쪽 아래에 고정되어 항상 표시된다. 화살표 없는 기본형이며, 끄는 거리에 따라 속도가 바뀌지 않는다.
옵션 버튼, 상호작용 버튼 80×80, 220×220 옵션 버튼은 오른쪽 위, 상호작용 버튼은 오른쪽 아래에 둔다.
